argument-hint: [decision id or what happened, e.g. "the pricing change went fine"]

Use the `persona-retro` skill.

$ARGUMENTS

Find the decision on record, read the concerns each seat raised, and ask the user
to mark which ones actually materialized — list them rather than asking an open
question. Record concerns that came true but nobody raised under `blindSpotsHit`.

Only mark a concern realized if it actually happened. Generous marking destroys
the only honest calibration signal there is.

If no arguments were given, list decisions awaiting a retro and ask which to close.
